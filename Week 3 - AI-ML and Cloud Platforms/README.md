# Week 3 — AI/ML and Cloud Platforms

This folder provides a small end-to-end AI/ML workflow and a cloud readiness checklist. It uses a local sample dataset and does not require cloud credentials.

## Files
- `ai_ml_pipeline.py` — loads example data, splits it into train/test sets, trains a regression model, and reports evaluation metrics.
- `cloud_platform_checklist.md` — deployment planning, account safety, cost and security checks.

Run:
```bash
python "Week 3 - AI-ML and Cloud Platforms/ai_ml_pipeline.py"
```

Use the cloud checklist before deploying to AWS, Azure or Google Cloud. Never commit access keys, passwords, tokens or private data.
