# Week 1–2 — Foundations

This folder contains runnable beginner exercises aligned with the supplied outline's foundations topics: Python programming, NumPy/Pandas, visualization, mathematics, descriptive statistics and probability.

## Exercises
1. `python_basics.py` — variables, types, conditions, loops, functions, collections, exceptions and file I/O.
2. `data_analysis.py` — NumPy arrays, Pandas DataFrames, summary statistics and a Matplotlib chart.
3. `statistics_probability.py` — mean, median, variance, standard deviation and simple probability examples.

Run from the repository root:
```bash
python "Week 1-2 - Foundations/python_basics.py"
python "Week 1-2 - Foundations/data_analysis.py"
python "Week 1-2 - Foundations/statistics_probability.py"
```

These are practice exercises built from the course topics, not verbatim copies of the official numbered task sheet.
