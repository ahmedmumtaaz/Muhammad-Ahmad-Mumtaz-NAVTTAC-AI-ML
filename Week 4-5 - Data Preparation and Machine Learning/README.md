# Week 4–5 — Data Preparation and Machine Learning

## Files
- `data_preparation.py` — missing values, duplicate rows, categorical encoding, scaling and train/test split.
- `machine_learning_models.py` — baseline regression and classification examples with evaluation metrics.
- `modeling_notes.md` — concepts and questions for review.

Run:
```bash
python "Week 4-5 - Data Preparation and Machine Learning/data_preparation.py"
python "Week 4-5 - Data Preparation and Machine Learning/machine_learning_models.py"
```

The sample datasets are generated in code so no external data download is required.
