# Capstone Project (Weeks 9–12): Customer Churn Prediction

Build a synthetic-data end-to-end ML project to predict customer churn. This capstone demonstrates data generation, preprocessing, model comparison, evaluation, sample inference, artifact saving, monitoring concepts, and responsible AI considerations.

## Tasks
1. Define the prediction problem and feature list.
2. Generate a synthetic dataset and inspect target balance.
3. Preprocess numeric and categorical features using a pipeline.
4. Train logistic regression and random forest; compare Accuracy, Precision, Recall, F1.
5. Review confusion matrix and sample inference.
6. Save the pipeline artifact and metadata.
7. Draft monitoring, retraining, drift and rollback plans.
8. Discuss fairness, privacy, transparency, and limitations.
9. Prepare final report and presentation.

The capstone is educational only and uses synthetic data.
